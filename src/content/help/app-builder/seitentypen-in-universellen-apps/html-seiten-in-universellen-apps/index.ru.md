Другие [типы страниц приложения]({{< relref "help/app-builder/seitentypen-in-universellen-apps/ueberblick" >}}) предлагают множество вариантов настройки, но задают структуру и поведение страницы. С помощью **HTML-страниц** вы можете добавить в приложение полностью индивидуальные страницы на основе HTML, JavaScript и CSS. Так вы сможете оформить приложения точно по своим представлениям и без проблем реализовать даже сложные взаимодействия. **Типичные сценарии использования**:
- Индивидуально оформленные формы, списки и информационные страницы
- Собственные типы диаграмм или схем с кликабельными элементами
- Комбинированные представления, например таблица и отдельная запись на одной странице

![Пример HTML-страницы](images/html-page.png)

HTML-страницы могут отображать **статическое содержимое**, однако свой истинный потенциал они раскрывают в сочетании с **данными базы**. Как и другие типы страниц App Builder, они могут получать данные из базы и изменять записи в базе. При **оформлении пользовательского интерфейса** практически нет ограничений. Всё, что можно реализовать с помощью HTML, CSS и JavaScript, вы можете встроить в своё приложение в виде HTML-страницы.

{{< warning headline="Пока не no-code-подход" >}}

В настоящее время этот тип страницы рассчитан на **пользователей с опытом программирования**. Весь код страницы необходимо создать вне SeaTable, а затем загрузить в приложение единым пакетом. Однако функция ИИ, с помощью которой в будущем вы сможете создавать HTML-страницы на естественном языке и без знаний программирования, уже находится в разработке.

{{< /warning >}}

## Как создать HTML-страницу

1. Откройте приложение в **режиме редактирования**. Для этого наведите курсор мыши на приложение и нажмите на **значок карандаша** {{< seatable-icon icon="dtable-icon-rename" >}}.
   ![Редактирование приложений](images/edit-apps.png)
2. Нажмите вверху слева на **оранжевый круг со значком плюса** и затем выберите **Добавить HTML-страницу**.
   ![Добавить HTML-страницу](images/add-html-page.png)
3. Задайте странице **имя** и при желании определите **значок** для страницы.
   ![Создание HTML-страницы](images/create-html-page.png)
4. Подтвердите кнопкой **Отправить**.
5. Создайте на своём устройстве **zip-файл**, содержащий файлы HTML, JavaScript и CSS.
6. **Загрузите файл**, нажав на предусмотренную для этого область или перетащив файл в неё.
   ![Загрузка zip-файла](images/upload-zip-file.png)
7. После этого SeaTable отобразит файл как **страницу в приложении**.

{{< warning headline="Внимание" >}}

Размер zip-файла не должен превышать **10 МБ**, и он должен содержать HTML-файл с именем **index.html**.

{{< /warning >}}

## Как создать необходимые файлы

Существует **два способа** создать HTML-страницу и предоставить её в виде zip-файла:
- **Low-code-подход**: оформите страницу в **визуальном HTML-редакторе**, свяжите её с вашей базой с помощью готовых **фрагментов кода**, при желании добавьте **изображения и графику** и упакуйте всё в **zip-файл**. Этот способ идеально подходит для индивидуально оформленных форм, дашбордов и страниц с простыми операциями чтения и записи.
- **Подход разработчика**: как только вы захотите создать более крупные HTML-страницы с более сложной логикой, например когда элементы страницы должны взаимодействовать друг с другом, вам потребуется **полный набор инструментов JavaScript**. Для разработки необходимы **Node.js** и **npm**, **сервер разработки** с живой перезагрузкой, а также **API-токен**, созданный в базе.

Дополнительную информацию, примеры и шаблоны вы найдёте в нашем [руководстве для разработчиков](https://developer.seatable.com/html-pages/).
