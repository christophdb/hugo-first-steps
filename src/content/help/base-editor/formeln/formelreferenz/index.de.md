Eine der stärksten Funktionen von SeaTable verkörpert die [Formel-Spalte]({{< relref "help/base-editor/spaltentypen/die-formel-spalte" >}}). Mit Formeln können Sie die **Werte** von anderen Spalten der aktuellen Tabelle – oder sogar einer anderen [verknüpften]({{< relref "help/base-editor/spaltentypen/die-verknuepfungsspalte" >}}) Tabelle – zählen, für **Berechnungen** nutzen, umwandeln, auswerten, miteinander kombinieren und vergleichen. Darüber hinaus können Formeln **Konstanten** und **logische Werte** zurückgeben.

Sie können beliebig viele Formel-Spalten hinzufügen, die wiederum mit den Resultaten aus existierenden Formel-Spalten weiterrechnen. Der große Vorteil: Die Ergebnisse in Formel-Spalten werden **automatisch aktualisiert**, sobald die Werte in den beteiligten Spalten geändert werden.

Momentan bietet SeaTable die folgenden Funktionen an, wenn Sie den Spaltentyp **Formel** auswählen:

- Zeilen
- Konstanten
- Operanden
- Mathematische Funktionen
- Textfunktionen
- Datumsfunktionen
- Logische Funktionen
- Statistische Funktionen
- Verknüpfungsfunktionen

![Formeleditor in SeaTable mit Funktionsliste und Beispiel](images/formula.jpg)

Außer den Funktionen gibt es im Formeleditor noch eine bzw. mehrere **Spaltenlisten**. Das sind die auswählbaren Spalten in der aktuellen Tabelle und gegebenenfalls jene Spalten in den verlinkten Tabellen. Wenn Sie rechts auf das "+"-Symbol klicken, wird die **Spaltenreferenz** in das Eingabefeld eingefügt, und zwar im Format {Spaltenname} bzw. {Verknüpfungsspalte.Spaltenname}. Diese Elemente können Sie direkt in Ihrer Formel nutzen. Alternativ können Sie natürlich auch Spaltennamen in geschweiften Klammern per Hand eingeben.

In diesem Artikel zeigen wir Ihnen eine komplette Übersicht über alle Formeln in SeaTable mit passenden Beispielen. Wenn Sie nach einer bestimmten Funktion suchen, können Sie die Tastenkombination {{< key "Ctrl" >}}+{{< key "F" >}} nutzen, um schnell einen Eintrag auf dieser Seite zu finden.
