Tem dados que deseja partilhar com um maior número de pessoas ou mesmo tornar acessíveis ao público? Para estes casos de utilização, as **ligações externas** são a solução ideal!

As ligações externas fornecem **acesso de leitura** aos dados de uma base **sem** que seja necessário **iniciar sessão** no SeaTable. Além disso, as ligações externas podem ser **incorporadas em páginas web**, o que permite disponibilizar facilmente online pequenas e grandes coleções de dados.

Por conseguinte, as ligações externas oferecem-lhe inúmeras possibilidades interessantes. Este artigo explica quais são e como as utilizar.

## Funcionamento e tipos de ligações externas

Uma ligação externa é um **URL** através do qual pode aceder a uma coleção de dados no SeaTable com **acesso de leitura**. Essa coleção de dados pode ser uma [base]({{< relref "help/startseite/bases/allgemeines-zu-bases" >}}) ou uma [vista]({{< relref "help/erste-schritte/einfuehrung-funktionen/ansichten/" >}}).

- **Ligação externa para uma base**: Ao abrir esta ligação externa, o visitante pode **ver** todos os dados guardados numa base, incluindo todas as tabelas. O visitante pode ainda aceder a **todas as vistas existentes** e às [estatísticas]({{< relref "help/base-editor/statistiken/anleitung-zum-statistik-modul" >}}). Além disso, pode utilizar as **ferramentas de avaliação** [agrupamento, ordenação e filtros]({{< relref "help/base-editor/ansichten/gruppierung-sortierung-und-filter" >}}).
- **Ligação externa para uma vista**: Uma ligação externa deste tipo concede **acesso de leitura a _uma_ vista específica de uma tabela**. As restantes vistas e tabelas da base, bem como as **linhas e colunas ocultas**, permanecem **ocultas** aos utilizadores da ligação externa. Saiba mais no artigo [Criar uma ligação externa para uma vista]({{< relref "help/startseite/freigaben/externen-link-fuer-eine-ansicht-erstellen" >}}).

As ligações externas são, por princípio, **ligações públicas**, ou seja, a ligação pode ser aberta por qualquer pessoa, independentemente de ter ou não sessão iniciada no SeaTable. Esta é também uma das principais [diferenças em relação ao link de convite]({{< relref "help/startseite/freigaben/einladungs-link-erklaert" >}}).

As ligações externas são sempre adequadas quando pretende disponibilizar dados de bases a **pessoas externas**. Podem ser os resultados de um inquérito, uma lista de preços ou o calendário de um evento ou do lançamento de um produto. Uma utilização especial das ligações externas é a sua **incorporação em páginas web**, sobre a qual pode saber mais abaixo.

## Como criar uma ligação externa para uma base

![Criar uma ligação externa](images/create-external-link.gif)

1. Vá para a **página inicial** do SeaTable.
2. Mova o ponteiro do rato para a **base** que pretende partilhar e clique nos **três pontos** que aparecem à direita.
3. Selecione a opção **Partilhar**.
4. Clique em **Ligação externa**.
5. Decida se pretende adicionar uma **proteção por palavra-passe**, uma **data de expiração** e uma **descrição**, ativando as caixas correspondentes.
6. Selecione se pretende gerar um **URL aleatório** ou definir um **URL próprio**.
7. Clique em **Criar**.

Agora pode **copiar a ligação** e partilhá-la com quantas pessoas quiser.

## Incorporação de uma ligação externa numa página web

As ligações externas são ótimas para publicar um determinado número de registos num site. Os visitantes do site veem os conteúdos que foram partilhados, mas não os podem alterar.

Com uma simples _etiqueta embed_, pode integrar uma base ou uma vista numa página web através de uma ligação externa. Por exemplo, os [modelos do SeaTable]({{< relref "templates" >}}) estão incorporados no nosso site através de ligações externas.
