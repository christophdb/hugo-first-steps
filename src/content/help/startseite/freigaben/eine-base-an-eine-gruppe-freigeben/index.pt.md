As bases no SeaTable pertencem sempre a um **utilizador** ou a um **grupo**. Por isso, pode partilhar bases quer com grupos quer [com utilizadores individuais]({{< relref "help/startseite/freigaben/anlegen-einer-benutzerfreigabe" >}}). Este artigo trata da partilha de uma base com um grupo inteiro.

Aqui pode decidir individualmente para cada base se deve ser uma **partilha de leitura** ou uma **partilha de leitura e escrita**.

{{< warning  headline="Nota"  text="Se conceder a um grupo **acesso de leitura e escrita**, **todos os membros** do grupo podem **ver** e **editar** o conteúdo da base. No entanto, **não podem** instalar **plug-ins** nem **partilhar** a base com outros utilizadores e grupos." />}}

Pode partilhar as suas bases tanto **a partir da página inicial** como **dentro de uma base**.

## Partilhar uma base a partir da página inicial

![Partilhar uma base com um grupo](images/Freigabe-einer-Base-an-eine-Gruppe.gif)

1. Vá para a **página inicial do SeaTable**.
2. Mova o ponteiro do rato para a **base** que pretende partilhar e clique nos **três pontos** que aparecem à direita.
3. Clique em **Partilhar**.
4. Vá para **Partilhar com grupo**.
5. Selecione o **grupo** desejado com o qual pretende partilhar a **base**.
6. Defina se pretende atribuir **direitos de leitura e escrita** ou apenas **direitos de leitura**.
7. Clique em **Submeter**.

## Partilha dentro da base

![Partilha dentro da base](images/share-a-base.png)

Se estiver atualmente **numa base**, também pode criar uma partilha sem ter de mudar para a página inicial. Para o fazer, clique no **ícone de partilha** {{< seatable-icon icon="dtable-icon-share" >}} no canto superior direito das **opções da base**. A janela que se abre para criar uma partilha é exatamente igual à da página inicial. Basta seguir as instruções acima, a partir do passo 4.

## Limitações

- **Só** pode partilhar bases com grupos dos quais já é **membro**.
- As bases que **criou você mesmo** podem ser partilhadas em qualquer altura, ao passo que as bases pertencentes a um grupo só podem ser partilhadas com outros grupos por **proprietários** e **administradores**.
- Um grupo com o qual partilhou uma base **não tem direitos de proprietário** e, portanto, **não pode**, por exemplo, alterar o nome da base.

Para saber como partilhar **tabelas e vistas individuais** de uma base com um grupo, consulte o artigo [Criar partilha personalizada]({{< relref "help/startseite/freigaben/benutzerdefinierte-freigabe-erstellen" >}}).
