Вы хотите **поделиться** не всей базой, а **отдельными таблицами**? Вы можете сделать это с помощью **настраиваемого общего доступа** для определенных [пользователей]({{< relref "help/startseite/freigaben/eine-base-an-eine-gruppe-freigeben" >}}).

## Общий доступ к отдельным таблицам через домашнюю страницу

![Общий доступ к отдельным таблицам с домашней страницы](images/share-single-tablesheets-from-the-start-page.png)

1. Перейдите на **домашнюю страницу** SeaTable.
2. Наведите курсор мыши на **базу**, отдельные таблицы которой вы хотите сделать общими.
3. Нажмите на **три точки**, которые появятся справа.
4. Выберите пункт меню **Поделиться**.
5. Затем откроется **окно**, в котором вы можете создать различные общие доступы.

## Общий доступ внутри базы

![Общий доступ внутри базы](images/share-a-base.png)

Если вы находитесь **в базе**, вы также можете создать общий доступ, не переходя на домашнюю страницу. Для этого щелкните по **значку общего доступа** {{< seatable-icon icon="dtable-icon-share" >}} в правом верхнем углу **опций базы**. Откроется такое же окно для создания общего доступа, как и на домашней странице.

## Создание настраиваемого общего доступа

Подробное объяснение необходимых шагов см. в статье [Создать пользовательский общий доступ]({{< relref "help/startseite/freigaben/benutzerdefinierte-freigabe-erstellen" >}}).
